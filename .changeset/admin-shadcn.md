New package: shadcn/ui-styled React components for @machize/admin. Ships the
authentic shadcn primitives (Button with cva variants + Radix Slot asChild,
Input, Label, Table, Card, Badge — using the cn utility over clsx + tailwind-merge)
and styled DataTable/ResourceForm that render the Zod-derived admin view models.
Drop-in for any shadcn/Tailwind project.
